### Training Data Files

We provide three datasets: Office, Clothing, and Baby with public researchers. The training data files can be downloaded from [Google Ddrive](https://drive.google.com/drive/folders/1kGsm9RaUnhn3ujJoEi3MIZQofHb5XRmt?usp=sharing) 

- `graph_xxxx.txt` Aspect-related Train file. Each line is a user with her/his positive interactions with items: (userID and itemID)
- `test.txt` Test file. Each line is a user with her/his several positive interactions with items: (userID and itemID)

### LLM-generated Semantic-aware Reviews

We provide downloadable files that include the results (`data.pkl`) generated by the LLM during the semantic aspect extraction process. These results output summaries that identify the presence of specific aspects within a review. For example:

```
{
	'reviewerID': 'A1AQYAGTO2O43P',
	'asin': 'B00HFJWKWK',
	'reviewerName': 'Dave',
	'helpful': [0, 0],
	'reviewText': 'works really well. great value for that price.',
	'overall': 5.0,
	'summary': 'great value for that price',
	'unixReviewTime': 1405987200,
	'reviewTime': '07 22, 2014',
	'explicit_quality': 'The customer commented that the product works really well, indicating that the quality of the product is good.',
	'explicit_functionality': 'N/A',
	'explicit_ease_of_use': 'N/A',
	'explicit_convenience': 'The customer commented that the product works really well, indicating that the customer found the product convenient to use.',
	'explicit_comfort': 'N/A',
	'explicit_durability': 'N/A',
	'explicit_design': 'N/A',
	'explicit_price': 'The customer commented that the product is a great value for that price, indicating that the customer found the price reasonable.'
}
```

if the LLM generates the output: “*The customer commented that the product works really well, indicating that the quality of the product is good.*”, it
means an interaction on quality. Otherwise, the LLM generates the output: “*N/A*” to indicate there is no interaction in this aspect. 
 
## Examples of LLMSAGCN with 8 aspects

The below command will repeat the training progress of some of our best results. For more options, please check `parse.py`.

* command

```shell
# baby
python main.py \
    --layer 6   \
    --dataset baby  \
    --model sagcn   \
    --mode concat   \
    --explicit_factors "quality" "functionality" "comfort" "ease_of_use" "design" "durability" "size" "price"   \
    --has_implicit 0   \
    --explicit_graph specific

# clothing
python main.py \
    --layer 6   \
    --dataset clothing  \
    --explicit_factors "quality", "comfort", "appearance", "style", "fit", "design", "size", "price"

# office
python main.py \
    --layer 5   \
    --dataset office  \
    --explicit_factors "quality", "functionality", "ease_of_use", "convenience", "comfort", "durability", "design", "price"
```

If you'd like to try LightGCN using our code, you can run the following command:

```shell
# baby
python main.py  \
    --layer 3   \
    --decay 0.01    \
    --dataset baby  \
    --model lgn   \
    --has_implicit 1   \
    --explicit_graph common

# office
python main.py  \
    --layer 5   \
    --dataset office  \
    --model lgn   \
    --has_implicit 1   \
    --explicit_graph common

# clothing
python main.py  \
    --layer 4   \
    --dataset clothing  \
    --model lgn   \
    --has_implicit 1   \
    --explicit_graph common
```
